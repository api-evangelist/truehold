# Truehold

> Truehold is a residential real estate company that buys a home from its owner and rents it
> back to that same owner — a residential sale-leaseback — so the owner can convert home equity
> into cash without moving. Founded in 2021 in St. Louis, Missouri, it also transacts portfolio
> and multifamily sales with investors and, through Truehold Financial (Jacksonville, Florida),
> originates DSCR, fix-and-flip and other investor lending products.

IMPORTANT FOR AGENTS: Truehold publishes NO public API. There is no developer portal, no API
reference, no OpenAPI/AsyncAPI/GraphQL contract, no SDK on any public package registry, no MCP
server and no A2A agent card. Every path below is a human-facing marketing or account page.
Verified 2026-08-30 by probing /openapi.json, /swagger.json, /api-docs, /docs, /llms.txt,
/apis.json and the full /.well-known/* set on www.truehold.com, my.truehold.com and
app.truehold.com — all 404. api.truehold.com, developer.truehold.com and docs.truehold.com do
not resolve. Do not attempt to construct API calls against these hosts.
